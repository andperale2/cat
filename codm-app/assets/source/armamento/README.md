# Directorio de Recursos Originales del PDF: ARMAMENTO COMD.pdf

Esta carpeta está reservada exclusivamente para alojar el documento original `ARMAMENTO COMD.pdf` (344 páginas) y las imágenes auténticas extraídas directamente del juego / armero oficial.

### Normas de Integridad de Datos:
1. **Sin recursos inventados:** Ningún accesorio, estadística o código debe ser inventado ni sustituido por SVGs o ilustraciones genéricas.
2. **Imágenes auténticas:** Los accesorios o armas sin imagen extraída mantendrán el estado visual «Imagen no disponible».
3. **Estructura para imágenes extraídas:**
   - `weapons/`: Fotografías oficiales y modelos de armas del PDF.
   - `attachments/<arma_id>/<ranura>/`: Recortes auténticos de accesorios del juego.
